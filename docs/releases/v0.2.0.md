# minicrond 0.2.0

The 0.2.0 release adds an optional Unix-only daemon while keeping the
existing TCP, bearer-token, CLI, API, and UI defaults.

- `server.tcp_enabled = false` serves the full API, SSE, and embedded UI on
  the private Unix socket without opening a TCP port or issuing a new token.
- The UI can use an authenticated proxy to a Unix-only daemon without
  receiving a bearer token. A later 401 ends that browser session.
- Jobs and workers can run under an unprivileged numeric UID without a
  passwd entry. Explicit `HOME` and `working_dir` values keep their
  environment predictable.
- `If-None-Match: *` gives API clients an atomic create-only definition
  operation, so automated setup cannot overwrite an existing name.

Proxy deployments must authenticate every request and treat access as full
operator privilege. See the [operations runbook](../operations.md#unix-only-and-proxied-operation).
