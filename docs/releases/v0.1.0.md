# minicron v0.1.0

Initial local-mode release: strict daemon settings, SQLite-authoritative definitions with explicit TOML import/export, five-field cron and persistent intervals, local job execution, one-instance workers, SQLite history, bounded tagged zstd logs, REST/SSE, Unix socket, bearer rotation, CLI, and embedded dashboard.

## Upgrade and rollback

This is schema 1. Before replacing a pre-release binary, stop the daemon and copy the entire data directory. Upgrade by replacing the binary and restarting. To roll back, stop the daemon, restore that directory snapshot, restore the old binary, and restart. Never run two daemons against one data directory or downgrade a live newer-schema database.

## Known limits

Process groups do not contain deliberately daemonized descendants. Local pure-Go user lookup is limited to numeric IDs and local passwd/group sources. Logs preserve daemon ingestion order, not unknowable kernel stdout/stderr write order. System mode, retries, queues, notifications, Docker, S3, and backup commands are not included.
