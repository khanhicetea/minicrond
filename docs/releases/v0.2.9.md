# minicrond 0.2.9

The 0.2.9 release changes the built-in run-history limits:

- Each definition keeps at most 10,000 runs.
- Run history is kept for at most 7 days.
- Both limits apply; retention removes a run when either limit is exceeded.

This is a breaking default change for configurations that omit
`storage.keep_runs_default` or `storage.keep_for_default`. Set explicit values
before upgrading to preserve the previous limits of 200 runs and 30 days.

The separate log-archive age default remains 30 days.
